Straight talk

Active development, so here is exactly where it stands.

Works today

  • One server hosted here, free. Or take the code and run it anywhere.
  • Tested before you get it, and fixed if something fails
  • Drops into Claude Desktop, or runs behind HTTP wherever you put it
  • Code published to a Gist on your own GitHub account, or downloaded
  • A public catalogue you can browse without an account

Not available yet

  • Paid plans. Nothing is for sale, so no price is quoted anywhere.
  • Pushing straight to a GitHub repo. Gated to a paid tier, and there is no paid tier to buy. Free accounts publish a Gist.
  • More than one hosted server. Free accounts get one. Raising that needs a paid tier, and there isn’t one.
