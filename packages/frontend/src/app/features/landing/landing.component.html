It is an MCP server too

POST /mcp speaks MCP Streamable HTTP, authenticated with an API key. An agent can generate a server, answer its own clarifying questions, fetch the code and search the catalogue without a browser in the loop.

Straight talk

Active development. You should hear it from us rather than find out.

Works today

  • Start from a repo, a docs URL, a service name or a sentence
  • Every server tested before you get it, and fixed if it fails
  • Drops straight into Claude Desktop, or runs behind HTTP wherever you put it
  • Code to a public Gist on your own GitHub account, or downloaded
  • The MCP endpoint and its six tools

Not available yet

  • Hosting. We don’t run your server for you yet. You take the code and run it wherever you like.
  • Paid plans. Nothing is for sale, so no price is quoted anywhere.
  • Pushing straight to a GitHub repo. Gated to a paid tier, and there is no paid tier to buy. Free accounts publish a Gist.
  • OpenAPI or GraphQL specs. We don’t read them. Point at the repo or the docs instead.
