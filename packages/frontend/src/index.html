MCP Everything

Describe an API. Get a server that runs.

MCP Everything turns a GitHub repository, a documentation site, a service name or a plain-English description into a Model Context Protocol server — then compiles it, starts it in a Docker sandbox and calls its tools over JSON-RPC, with up to five automatic repair rounds, before handing it to you.

What you get

  • A server that was actually built and run, not just written
  • Both MCP transports: stdio by default, MCP Streamable HTTP when MCP_TRANSPORT=http is set
  • Source, tests, a Dockerfile and documentation, published to a public Gist on your own GitHub account or downloaded
  • Sign-in with GitHub, Google, or an email address and password
  • Five generations a month, free. Nothing is for sale and no card is collected.

For AI agents

MCP Everything is itself an MCP server, at POST https://mcpeverything.com/mcp — MCP Streamable HTTP, stateless, authenticated with an API key prefixed mcpe_ sent either as an X-API-Key header or as Authorization: Bearer. Keys are created on the account page. It exposes six tools: generate_mcp_server, continue_generation, get_generation_status, get_generated_server, list_conversations and search_marketplace. A machine-readable summary of this site is published at /llms.txt.

Not available yet

  • Hosting MCP servers on MCP Everything infrastructure — the Kubernetes path now runs end to end on real hardware, but it is not open to accounts
  • Paid plans, billing and subscriptions — nothing is for sale
  • Pushing to a GitHub repository — implemented, but gated to a paid tier that cannot currently be purchased. Free accounts publish to a public Gist.
  • OpenAPI or GraphQL specification input — no specification parser exists
