MCP Everything

Your assistant can describe your API. Now let it use it.

Name a service, paste a repository, point at a docs site, or just say what you want. MCP Everything gives your AI assistant the tools to call it: a working Model Context Protocol server, hosted here or run wherever you like.

What you get

  • A set of named tools your assistant can call, built and tested before you get it, and fixed if something fails
  • One server hosted here free, or take the code and run it anywhere
  • Something that drops straight into Claude Desktop, or runs behind HTTP wherever you put it
  • Source, tests and documentation, published to a public Gist on your own GitHub account (connect it first) or downloaded
  • Sign-in with GitHub, Google, or an email address and password
  • Five generations a month, free. Nothing is for sale and no card is collected.

For AI agents

MCP Everything is itself an MCP server, at POST https://mcpeverything.com/mcp. MCP Streamable HTTP, stateless, authenticated with an API key prefixed mcpe_ sent either as an X-API-Key header or as Authorization: Bearer. Keys are created on the account page. It exposes eight tools: generate_mcp_server, continue_generation, get_generation_status, get_generated_server, list_conversations, search_marketplace, search_tools and call_tool. The last two find and run the tools of the MCP servers you host here, so one connection reaches all of them. A machine-readable summary of this site is published at /llms.txt.

Not available yet

  • Paid plans, billing and subscriptions. Nothing is for sale.
  • More than one hosted server. Free accounts get one, and there is no paid tier to buy.
  • Pushing straight to a GitHub repository. Gated to a paid tier, and there is no paid tier to buy. Free accounts publish to a public Gist.
  • OpenAPI or GraphQL specs. We don’t read them; point at the repository or the docs instead.
